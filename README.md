# NEXORA AI — AI Technology Website

A responsive, static front-end concept website for an AI technology brand, created for a web development subject activity.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, colors, and visual styling

## Sections
- Home / hero
- About Nexora
- Platform features
- AI use cases
- Contact section

## Run locally
Open `index.html` in a web browser. Keep `index.html` and `style.css` in the same folder.

## Deployment
This project can be published with GitHub Pages: open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

## Note
Nexora is a fictional concept for educational purposes. The site is a static front-end demo; it does not provide real AI services or process contact form submissions.
